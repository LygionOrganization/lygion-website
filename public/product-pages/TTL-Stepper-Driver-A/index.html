TTL STEPPER DRIVER

把步进电机接入机器人总线

TTL Stepper Driver (A)

面向机器人应用的总线步进驱动板。上位机发送位置、速度、电流等指令，驱动板实现底层的运动控制。

控制模式 关键参数
  • 1 Mbps默认 TTL 总线通信
  • DC 9-26V驱动电源输入
  • 1.5A最大电机相电流
总线控制像控制舵机一样控制步进电机
简单易用易扩展
一根总线可控制252个设备
位置模式 / 速度模式控制机器人关节精准转动
控制机器人车轮连续转动
速度模式支持支持心跳保护：如控制器长时间没有发送新指令，电机会自动停止，避免程序异常后车轮继续转动
同步接口适合双丝杆、升降台、多轴联动
控制器仅需要控制一个设备，其余从动设备即可自动同步动作
控制更简单
限位保护由底层实现的限位和运行保护
控制器中不需要写限位保护相关代码，即可可靠实现机构动作需要自动限位保护的场景

WHAT IT SOLVES

简单易用，控制多个步进电机

传统步进电机控制方案需要控制器持续输出脉冲，并自己处理速度曲线、同步和限位。TTL Stepper Driver (A) 在底层实现这些运动控制，让主控只需要通过 TTL 总线发送简单指令即可轻松控制步进电机。

01

通过总线控制步进电机

多个步进驱动板可设置独立 ID 并接入同一总线，简化机器人系统复杂度。

多设备同时控制
02

平滑启停

通过速度和加速度参数控制电机转动，自动进行插值计算，减少突然启动、停止带来的冲击。

运动更可控
03

限位在底层处理

当需要限位开关时，最小位与最大位限位接口可阻止电机继续向危险方向运动，不需要应用层轮询处理。

更安全的机构保护
04

状态可读取

可读取位置、速度、电压、温度、移动标志等状态，方便调试和上层控制闭环。

可反馈驱动器状态

CONTROL MODES

多种控制模式，更实用

位置模式控制绝对位置和多圈运动，适合机器人关节、转台、丝杆定位。
速度模式连续正反转，可设置速度与加速度，适合车轮、传送带等连续旋转机构。
从动模式通过同步输入 / 输出让多台电机动作一致，适合多丝杆同步驱动场景。

TTL BUS SYSTEM

适配大部分主流控制器

PC、树莓派、Jetson 等控制器可通过 TTL Adapter (A) 的 USB 接口接入；
ESP32、STM32 等控制器可通过 TTL Adapter (A) 的 UART 接口接入（对于有 PCB 设计能力的用户，可以通过 UART 转单线 TTL 的电路接入）。
多个驱动板、编码器等总线设备可以组成机器人底层运动和感知网络。

PC / SBC 单板电脑使用 Python 语言开发机器人，机器人大脑直接控制各类总线设备。
MCU 控制器C++语言，适合机器人下位机做实时动作控制，机器人动作效率更高。
设备混合使用可与 TTL Encoder、总线舵机等设备协同工作，简化机器人系统复杂度。

BOARD INTERFACES

板载常用接口，简单实用

5264-3P电源输入与单线 TTL 总线通信。
XH2.54-4P双极步进电机 A+、A-、B-、B+。
XH2.54-3P x2最小位置和最大位置限位开关。（可不接）
GH1.25-3P x2同步控制信号输入与输出。（可不接）
HC1.25-3P可将灵影 TTL Encoder 并入同一总线供控制器读取；驱动板不处理编码器读数。（可不接）

SELECTION NOTE

适合小型机器人步进执行器

  • 更适合 42 系列、机身长度约 40mm 或以内的电机
  • 不建议驱动额定相电流超过 1.5A 的电机
  • 长期大电流会增加发热并可能触发过热保护
