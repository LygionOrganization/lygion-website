TTL BUS HUB

TTL 总线设备分线板

TTL-5264 8P Hub (A)

面向 5264-3P 接口设备的总线分线板。把通信、供电和分线功能整理在一块小板上，让总线设备接线更容易扩展。

可扩展设备 关键参数
  • 易于扩展8个 5264-3P 设备接口
  • 供电输入DC5521 插座与接线端子
  • 分组供电多组设备使用时，可分组供电
少接线一块 Hub 集成 8 路设备接口
易扩展适合多种总线设备混合控制系统
分组供电可以将不同供电规格的总线设备并入同一总线控制，具体可看 Wiki: 分组供电
尺寸小巧适合空间受限的应用场景

WHAT IT SOLVES

产品特性

机器人需要把多个不同供电需求的总线设备并入 TTL 总线同时控制。TTL-5264 8P Hub (A) 不改变通信协议，只负责把总线和电源可靠分配到多个 5264-3P 接口，尺寸小巧，易于集成在多种应用场景中。

01

接口集中

8 个 5264-3P 接口排列在同一块板上，设备数量变多时也能保持线束整洁。

将多个设备并入总线
02

尺寸紧凑

仅 44x21mm，适用于对空间敏感的四足、六足、机械臂等项目。

适合空间受限的应用场景
03

多板并联

方便多板/多组舵机使用不同电源、控制多组不同电压的总线设备

支持分组供电/供电解耦
04

易于集成

板载 DC5521 插座与接线端子，方便接入多种电源。

降低接线成本

POWER GROUPING

分组供电

通过多块 Hub 并联，可以让不同电压规格的总线设备并入同一条通信总线，同时由各自匹配的电源独立供电。例如图中两组设备分别使用 DC 12V 与 DC 7.4V 为 Hub 供电，供电电源互不影响。

通信共线多组设备共享 TTL 通信总线。
电源分组每组设备连接与其额定电压匹配的独立电源，避免不同供电规格互相影响。

ONBOARD RESOURCES

板载资源

  1. 01KF301-2P 供电端子，与 DC5521 供电接口内部相连，任接其一即可。
  2. 02电源指示灯。
  3. 03直径 3mm 安装固定孔，共 4 个。
  4. 04DC5521 供电接口，支持 DC 5–28V 输入。
  5. 05单线 TTL 板间通信接口（GH-1.25-3P）。
  6. 068 个 5264-3P 总线设备接口。

DIMENSIONS

结构尺寸

板体外形紧凑，宽度 21mm、主体长度 41mm，包含外伸接口的总长度约 43.3mm。安装孔直径为 3mm，横向孔距 15mm，纵向孔距 35mm。

EXPAND DEVICES

可扩展设备

适合连接 HX5264-3P 接口的 TTL 总线设备：灵影(Lygion)的总线产品，飞特(Feetech)的 STS、HLS、SCS 系列总线舵机

BUS SYSTEM

接线简单，易于使用

Hub 板适用于使用多种总线设备的机器人系统。多个驱动器、多个编码器、多只舵机接到同一条总线后，上位机只需要按设备 ID 发送指令，即可通过 USB 或 UART 接口与总线设备进行通信。

设备混用不同类型的总线设备可以连接到同一条总线上。
控制简单通过统一的接口和协议，简化设备控制流程。
接线清晰减少接线复杂度，提高系统可维护性。

NOTE

温馨提示

1. 分线板支持灵影和飞特的 5264-3P 接口设备、其它品牌的设备请自行评估接口线序是否兼容。
2. 产品提供 2D、3D图纸，详情可参考 产品 Wiki。
3. 供电需根据总线设备的电压要求进行供电，电流根据舵机负载大小进行选择。可联系客服推荐。
