TTL MULTIFUNCTION NODE

把遥控、灯光和辅助供电接进总线

TTL Node (A)

一块紧凑的 TTL 总线功能节点。它把 USB 调参、S.BUS 遥控输入、双路 PWM 可调输出、双路 RGB 状态灯和总线扩展集中到机器人内部。

查看核心功能 查看关键参数
  • 30 x 35 mm紧凑板卡尺寸
  • 1 Mbps默认 TTL 总线通信
  • 2 PWM + 2 RGB辅助输出与状态反馈
S.BUS 输入把航模接收器信号送进机器人总线
USB 调参PC、树莓派、Jetson 可直接连接
PWM 输出两路可调电源输出便于外设控制
RGB 状态两路状态灯让调试和运行更直观

WHAT IT SOLVES

它不是单纯转接板，而是机器人上的功能节点

很多机器人项目不只需要舵机通信，还需要遥控输入、状态指示、辅助供电和调参入口。TTL Node (A) 把这些零散需求集中到一块小板上，减少额外模块和线束。

01

遥控输入进总线

通过 S.BUS 接口读取航模接收器通道数据，让遥控器可以进入同一套控制链路。

适合遥控机器人
02

调试入口更直接

USB Type-C 可直连上位机，用于搜索设备、改 ID、改波特率、测试功能和读取状态。

上手更快
03

状态可视化

两路 RGB 状态灯可以显示运行、告警、模式或交互状态，让机器人更容易调试。

看到系统状态
04

末端外设更好接

双路 PWM 可调输出适合给简单外设做辅助控制，减少额外小板和飞线。

集中管理外设

CORE FUNCTIONS

一个节点，四类常用能力

S.BUS 遥控输入为 5V 航模接收器供电并读取通道数据，适合遥控底盘、机械臂和教学项目。
USB Type-C 调参与控制连接 PC、树莓派、Jetson 等设备，快速配置和测试节点板。
双路 PWM 可调输出控制 01 / 02 两路输出，文档示例使用 0-1000 的控制值。
双路 RGB 状态灯可通过软件或程序控制颜色，用于模式提示、状态反馈和调试。

BUS INTEGRATION

USB、TTL Adapter、ESP32S3 都能接入

TTL Node (A) 可以作为上位机调试入口，也可以通过 TTL Adapter (A) 加入总线，或接入 Robot Driver with ESP32S3 Lite 由嵌入式程序控制。多个节点与总线舵机共线时，需要先规划好设备 ID。

直接 USB适合调参、测试 RGB / PWM、读取 S.BUS 数据。
TTL Adapter把节点板与其它 TTL 总线设备接入同一系统。
ESP32S3 Lite适合把节点板嵌入机器人本体控制程序。

EASY TO START

先用 FD 软件点亮、调通、读到数据，再接入项目

TTL Node (A) 的使用门槛低，是因为它的常用功能都能先用软件或例程验证：S.BUS 输入、RGB 状态灯、PWM 输出、电压读取和 ID 修改都能按步骤检查。

STEP 01

USB 直连电脑

先用 USB Type-C 连接 PC，打开 FD 软件搜索设备，确认 ID、波特率和在线状态。

STEP 02

逐项测试核心功能

读取 S.BUS 通道，点亮 RGB 状态灯，调整 PWM 输出，读取总线电压，把每个功能单独验证清楚。

STEP 03

接入总线或程序

多块节点或总线舵机共线前先设置不同 ID，再用 Python / C++ / Arduino 例程接入实际项目。

FD SOFTWARE

把复杂节点拆成几个可点击验证的小功能

Node 的功能多，但不需要一次性写完整程序。先用 FD 软件和例程验证单项功能，再组合到机器人控制逻辑里，能显著降低调试难度。

S.BUS 读取读取航模接收器通道，把遥控输入接入总线系统。 RGB / PWM 控制快速测试状态灯和两路可调输出，适合末端外设验证。 Python / C++ SDK从上位机或嵌入式控制器读取电压、控制输出和管理节点。

APPLICATIONS

更适合带遥控、状态灯和外设输出的机器人节点

机械臂末端在夹爪附近集中状态灯、辅助输出和总线接入。
遥控移动机器人读取接收器信号，将遥控输入接入控制系统。
总线舵机系统作为总线里的功能节点，配合舵机和控制板工作。
教学 / 原型验证用 USB 和示例程序快速验证 S.BUS、PWM、RGB 和总线通信。
