TTL BUS HUB

小型 TTL 总线设备分线板

HC-1.25 8P Hub (A)

面向 HC-1.25-3P 小接口设备的总线扩展板。把通信、供电和分线功能整理在一块小板上，让总线设备接线更清楚、更容易扩展。

可扩展设备 关键参数
  • 易于扩展8 个 HC-1.25-3P 设备接口
  • 通信与供电HX-5264-3P 主控接口
  • 供电解耦独立 GH-1.25-3P 通信接口
少接线一块 Hub 集成 8 路设备接口
易扩展适合小型编码器与总线舵机
供电解耦可将通信与设备供电分开接入
尺寸小巧39 × 21mm，适合紧凑结构

WHAT IT SOLVES

产品特性

机器人需要把多个小型编码器、舵机等设备并入 TTL 总线同时控制。HC-1.25 8P Hub (A) 不改变通信协议，只负责把总线与电源可靠分配到 8 个 HC-1.25-3P 接口，尺寸小巧，易于集成在灵巧手和紧凑型机器人中。

01

接口集中

8 个 HC-1.25-3P 接口排列在同一块板上，设备增多时也能保持线束整洁。

将多个设备并入总线
02

尺寸紧凑

板体仅 39 × 21mm，适用于灵巧手、多足机器人和紧凑机械臂。

适合空间受限的场景
03

供电解耦

GH-1.25-3P 接口只连接通信线，可配合独立设备电源实现通信与供电解耦。

适配不同供电方案
04

易于集成

HX-5264-3P 主控接口同时接入通信与供电，可直接连接常用主控设备。

降低接线成本

WIRING

简单易用

主控侧HX-5264-3P 接口可直接连接 TTL Adapter (A) 或 Robot Driver，同时接入通信与供电。
设备侧8 路 HC-1.25-3P 接口用于连接 TTL Encoder E02、SC-0090-C043、SC-0090-C049、飞特总线舵机等设备。
供电解耦GH-1.25-3P 接口仅传输通信信号，可用于连接主控或其它 Hub，实现设备供电解耦。

DEVICE EXPANSION

八路设备集中接入

一块 HC-1.25 8P Hub (A) 可同时连接 8 个带 HC-1.25-3P 接口的总线设备。主控只需接入一条总线，即可按设备 ID 分别读取编码器或控制微型舵机。

通信共线8 路设备共享 TTL 通信总线，由主控按设备 ID 分别访问。
紧凑布线小型接口与轻量线束适合灵巧手、多足机器人等空间敏感项目。

可扩展的典型设备

BUS SYSTEM

接线简单，易于使用

通过 HC-1.25 8P Hub (A)，多个编码器和微型总线舵机可以汇入同一条 TTL 总线，由主控按 ID 统一读取和控制。

灵巧手多个关节角度反馈与微型执行器共线。
小机械臂减少穿过关节的线束数量。
传感器阵列多个小型总线节点集中读取。
