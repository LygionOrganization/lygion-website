STRUCTURE

让结构承担更多负载

LinkArm-LT 的结构路线与常见串联机械臂不同：LinkArm-LT 的机械结构与关节舵机共同承担负载，使臂体在移动、启停与保持姿态时更稳定。

负载分配更合理减少单个关节长期承受大负载的工况。
整体刚性更好负载、启停或底盘运动时，臂体姿态更稳定。
工作更持久相同任务下，舵机更不容易持续处于高发热状态。

BUILT-IN CONTROLLER

自带 ESP32-S3 下位机驱动板

LinkArm-LT 出厂内置完整的开源控制程序：Web应用，正逆解函数，JSON 通信接口等实用功能。上位机可以更专注于导航、感知和任务逻辑，机械臂执行由内置下位机承接。

零门槛使用机械臂开机自建热点，无需额外配置，手机、平板连接后可直接控制。
快速集成下位机内置逆解与插值算法，上位机仅需发送简单的 JSON 指令即可控制机械臂。
大小脑架构图中以树莓派为例，树莓派上位机与 ESP32-S3 下位机组成分层控制系统，效率更高。

CROSS-PLATFORM WEB APP

打开浏览器，就能使用机械臂

Web 应用由 LinkArm-LT 的 ESP32-S3 主控提供。用户无需安装专用 App，机械臂开机会自建热点，用户连接后，仅需打开浏览器即可使用。

电脑 / 手机 / 平板Web 应用支持跨平台、跨系统设备，简单易用。
设备状态与网络设置在浏览器中查看设备信息，并完成 Wi-Fi 相关配置。
开源全部例程所有示例代码均开源，方便用户学习和二次开发。

MOBILE BASE INTEGRATION

集成到多种移动机器人中

机械臂的特殊并联结构转为移动机器人设计，机械臂末端带有多种接口，可控制直流设备、板载 RGB LED、随机附赠摄像头支架，用于安装摄像头。

SCENE 01

TTL Node (A)

机械臂末端安装有总线节点板，用户可通过总线控制多种外设：两路可调电压的直流开关、两路 RGB LED 和面向远程遥控的 S.BUS 输入接口。

SCENE 02

摄像头安装

随机附赠摄像头安装支架，用户可以在机械臂末端安装摄像头，方便用户进行第一人称的夹取操作。

SCENE 03

JSON 指令交互

通过简单的 JSON 指令即可控制机械臂，提供 JSON 指令集和多种交互方式例程，方便用户快速集成。
