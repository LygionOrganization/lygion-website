WHAT IT DOES

它在机器人系统中做什么

Robot Driver 位于主机与执行器之间，负责接收控制指令、管理总线设备，也可以脱离主机执行本地任务。

独立控制器通过 Web 页面调试设备、控制动作和保存任务。
机器人下位机接收 PC、树莓派、Jetson 或其它主控发送的 JSON 指令。
执行器网关为 TTL、RS485、CAN 执行器提供统一的主机侧入口。

QUICK START

三步完成首次控制

1

连接设备与动力电源

选择对应总线接口，电源电压必须与执行器额定电压一致。

2

打开 Web 控制台

连接控制板热点，在浏览器访问 192.168.4.1。

3

测试设备并保存任务

确认设备 ID 和波特率，再调试动作或保存任务脚本。

供电提醒

Type-C 可以启动主控、OLED 和 Wi-Fi，但不能替代执行器动力电源。

CROSS-PLATFORM WEB CONTROL

无需安装 App 的跨平台无线控制

控制板提供 Wi-Fi 热点和 Web 控制界面。电脑、手机或平板连接后，都可以使用浏览器完成基础调试与控制。

AP + STA支持热点直连，也可接入已有局域网。
设备调试设置总线波特率、测试设备 ID 和发送 JSON。
任务脚本保存多步动作，并绑定按键或开机执行。

HARDWARE

控制、通信和本地交互集中在一块板上

主控与交互

ESP32-S3-WROOM-1、0.91 英寸 OLED、五向开关、蜂鸣器。

执行器接口

单线 TTL、RS485、CAN。

主机与扩展

USB CDC、UART Type-C、2×5 HAT 与扩展 IO。

电源

DC 6–20V 输入，板载 5V 5A DC-DC 与 3.3V LDO。

HOST INTEGRATION

先用 JSON 接口集成，再按需修改固件

多数项目可以把 Robot Driver 作为独立下位机使用。需要自定义实时逻辑或 IO 时，再进入 Arduino / PlatformIO 固件开发。

USB CDC

有线连接，适合调试和持续通信。

HTTP

适合配置、低频动作和快速原型。

WebSocket

适合无线实时指令与状态回传。

GPIO UART

适合机器人内部主从控制。

统一数据格式

USB CDC、HTTP、WebSocket 与 GPIO UART 使用统一 JSON 指令。

固件开发

支持 Arduino 框架与 VS Code + PlatformIO，板载 IO0 和 EN 用于下载与复位。
