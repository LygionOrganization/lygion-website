WHAT IT DOES

核心功能

Robot Driver 位于主机与执行器之间，可替主机承担一部分动作插值、正逆解计算算力，分担主机计算资源，负责接收控制指令、管理总线设备，也可以脱离主机独立执行任务。

独立控制器板载 Wifi 支持自建热点，通过 Web 页面调试设备、控制动作和保存任务。
机器人下位机接收 PC、树莓派、Jetson 或其它主控发送的 JSON 格式指令，JSON 指令人类可读易于调试。可执行高频正逆解计算，降低上位机程序复杂度，提升系统整体效率。
机器人外设网关为 TTL、RS485、CAN 总线设备提供统一的主机侧入口，也可以通过 ESP32-S3 的 IO 口进行扩展。

QUICK START

三步完成首次控制

1

连接设备与电源

连接总线设备，电源电压必须与执行器额定电压一致。

2

打开 Web 应用

手机连接控制板热点，在浏览器访问 192.168.4.1。

3

控制总线设备

可通过 Web 应用来为总线设备修改 ID，再控制总线设备或编辑动作脚本。

供电提醒

Type-C 可以启动主控、OLED 和 Wi-Fi，但不能替代执行器动力电源。

CROSS-PLATFORM WEB CONTROL

可跨平台无线控制

控制板开机自带 Wi-Fi 热点和 Web 控制界面。电脑、手机或平板连接后，就可以使用浏览器完成基础调试、控制和任务脚本编辑。

AP + STA支持热点直连，也可接入已有局域网。
设备调试设置总线波特率、测试设备 ID 和发送 JSON 指令。
任务脚本保存动作任务脚本，并绑定按键或开机自动执行。

HARDWARE

控制、通信和本地交互集中在一块板上

主控模组

ESP32-S3-WROOM-1、原生 USB CDC 与 板载 Wifi。

执行器接口

单线 TTL、RS485、CAN。

人机交互

0.91 英寸 OLED、五向开关、蜂鸣器。

电源

DC 6–20V 输入，板载 5V 5A DC-DC（用做 HAT 板时为树莓派供电） 与 3.3V LDO（可扩展其它外设）。

HOST INTEGRATION

到手即用，也支持自定义开发

多数项目可以把 Robot Driver 作为独立下位机使用。需要自定义正逆解等计算功能时，再使用 Arduino / PlatformIO 进行二次开发。

USB CDC

有线连接，适合调试和持续通信。

HTTP

适合配置、低频动作和快速原型。

WebSocket

适合无线实时指令与状态回传。

GPIO UART

适合机器人内部主从控制。

统一数据格式

USB CDC、HTTP、WebSocket 与 GPIO UART 使用统一 JSON 指令。

固件开发

支持 Arduino 框架与 VS Code + PlatformIO，板载自动下载电路，便于二次开发。
