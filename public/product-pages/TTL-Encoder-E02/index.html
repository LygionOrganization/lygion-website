TTL ABSOLUTE ENCODER

360°绝对角度实时反馈

TTL Encoder E02

小巧紧凑的 12bit 绝对角度磁编码器。可用于检测减速组输出轴角度、灵巧手、机械臂 Leader Arm 等场景，直接通过 TTL 总线读取关节的真实角度与速度，校准参数掉电不丢失，上电即可获得当前关节角度。

BOARD DETAIL

主要板载资源

磁编码 IC用于检测径向磁铁旋转角度，安装时需要关注磁铁中心与 IC 的相对位置，产品附赠 6*2.5 mm 径向磁铁。
HC1.25-3P TTL 总线和供电接口通过 GND / VCC / Signal 接入 TTL 总线。产品附赠连接线，多个编码器可接入 Hub 板 来并入总线。

TTL BUS SYSTEM

多个编码器，多种总线设备，共用一条总线

通过 TTL Adapter (A)、Hub 板 或带单线 TTL 接口的控制器，可以把多个编码器和多种其它类型的总线设备接入同一通信链路。每个设备设置独立 ID 后，上位机或 MCU 可以集中控制。

PC / Jetson / Raspberry Pi适合使用 Python 语言直接控制总线设备。
ESP32 / STM32 / Arduino适合使用 C++ 或 Arduino 语言进行嵌入式开发。
混合总线可与灵影的 TTL 总线设备、飞特的 TTL 总线舵机（HLS、STS系列）混合使用，支持多个 ID 同步读。

MAGNET INSTALLATION

安装要点

TTL Encoder E02 通过检测径向磁铁旋转来输出角度。安装时应让磁铁旋转轴线尽量对准编码 IC 中心，并控制合理间距大约 0.8~1.5 mm 之间；机械结构越稳定，反馈越精准。

同心磁铁旋转轴线尽量对准编码器 IC 中心。
间距磁铁与 IC 的距离建议按 1 mm 设计，0.8~1.5 mm 都可以使用。
固定磁铁和编码器板都需要可靠固定，避免振动或转动不同心导致读数波动。
校准装配完成后，可将当前位置设置为需要的基准角度，改参数掉电不丢失，后续开机即可直接使用。
