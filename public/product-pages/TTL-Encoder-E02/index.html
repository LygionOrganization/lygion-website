TTL ABSOLUTE ENCODER

让关节知道自己在哪里

TTL Encoder E02

一颗紧凑的 12bit 绝对角度磁编码器。装在关节、同步轮、齿轮或转向输出端，直接读取真实角度和速度，上电即可知道当前位置。

WHAT IT SOLVES

不是估算角度，而是读取真实输出

电机端角度不一定等于机构输出端角度。TTL Encoder E02 可以放到真正需要反馈的位置，让机器人系统直接获得关节、同步轮、齿轮或舵轮转向端的绝对角度。

01

减少回零流程

单圈绝对角度掉电保持，上电后即可读取当前位置，适合需要快速启动的关节和模组。

上电即读
02

反馈更靠近负载

安装在减速器输出端或传动末端，能看到机械间隙、同步带弹性和输出结构带来的真实变化。

输出端闭环
03

多关节集中采样

多个 E02 设置不同 ID 后可接入同一 TTL 总线，适合机械臂、灵巧手和底盘转向系统。

一条总线，多点反馈
04

结构小，接线少

HC-1.25-3P 接口承载 GND、VCC、Signal，能塞进更紧凑的机器人内部空间。

适合嵌入式安装

APPLICATIONS

哪里需要角度闭环，就把它装到哪里

机械臂 / Leader Arm读取每个关节的绝对角度，做示教、同步采样和姿态反馈。
灵巧手与小型关节在有限空间里获取手指或连杆位置，降低复杂传感器安装成本。
同步轮 / 齿轮 / 减速器直接检测输出端角度，适合与步进、舵机、减速结构组成闭环系统。
舵轮转向输出端用于底盘转向绝对角度反馈，让转向模组上电后快速进入控制状态。

TTL BUS SYSTEM

多个编码器，共用一条总线

通过 TTL Adapter (A)、Hub 板或带单线 TTL 接口的控制器，把多个 E02 编码器接入同一通信链路。每个设备设置独立 ID 后，上位机或 MCU 可以集中读取角度、速度和状态。

PC / SBC通过 TTL Adapter (A) 接入，适合调试、标定和数据采集。
MCU 控制器可由 ESP32、STM32、Arduino 等控制器读取反馈数据。
混合总线可与兼容 TTL 总线设备配合，形成统一底层反馈网络。

EASY TO START

不用先写完整程序，也能先把角度读出来

Wiki 已提供 FD 调试软件、Python 快速上手、C++ / Arduino 快速上手等入口。对新用户来说，可以先用软件确认设备在线，再用例程读取位置和速度，最后再接入自己的控制程序。

STEP 01

连接电脑或开发板

通过 TTL Adapter (A) 接入 PC、树莓派、Jetson；或用 MCU 接入 TTL 总线，先确认供电和设备 ID。

STEP 02

打开 FD 软件配置设备

搜索设备、查看 ID 与波特率、确认通信状态。需要多设备共线时，先逐个修改 ID，避免冲突。

STEP 03

运行例程读取数据

Python 适合 PC / SBC 快速验证；C++ / Arduino 适合 ESP32、STM32 等嵌入式控制器读取角度和速度。

FD SOFTWARE

先看到数据，再写控制逻辑

对编码器类产品，FD 软件最有价值的是“确认设备确实在线、ID 没冲突、波特率匹配”。这一步能把接线问题、供电问题和程序问题分开排查，降低第一次上手的挫败感。

Python 读取快速读取单圈位置、多圈位置和速度反馈。 C++ / Arduino把 E02 接入 MCU 项目，用于关节反馈和嵌入式控制。 校准与多圈装配后设置基准位置，并理解单圈与多圈读数边界。

MAGNET INSTALLATION

径向磁铁对准 IC，角度才可靠

TTL Encoder E02 通过检测径向磁铁旋转来输出角度。安装时应让磁铁与编码器 IC 保持同心，并控制合理间距；机械结构越稳，反馈越可信。

同心磁铁旋转轴线尽量对准编码器 IC 中心。
间距建议约 1mm，最大不建议超过 1.5mm。
固定磁铁和编码器板都需要可靠固定，避免振动导致读数波动。
校准装配完成后，可将当前位置设置为需要的基准值。
