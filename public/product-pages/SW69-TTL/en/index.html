PRODUCT POSITIONING

A straightforward path to omnidirectional motion

SW69-TTL is designed for mobile platforms that need forward, lateral and diagonal travel as well as in-place rotation. Its mechanics, motors, drivers and steering-angle feedback are packaged as one module for simpler chassis integration and commissioning.

01

High-torque steering

A stepper motor turns the wheel assembly through a timing-belt reduction. Open kinematics code and tutorials are available for chassis control.

02

Stepper wheel drive

The drive motor controls direction, speed and motion targets for the 69 mm wheel, with strong low-speed behavior, smooth starts and stops, and heartbeat protection.

03

Absolute wheel-angle feedback

The encoder reports the current steering angle and retains calibration data without power, so the module can initialize without a homing cycle.

04

Shared bus communication

Both TTL Stepper Driver (A) boards and the encoder connect to one single-wire TTL bus, alongside LYGION bus devices or compatible Feetech bus servos.

PRODUCT STRUCTURE

A compact, installation-ready assembly

The module combines a high-strength 6061 aluminum CNC frame, separate steering and drive motors, and a timing-belt reduction in a straightforward mechanical layout.

TTL BUS INTEGRATION

Control multiple modules over one bus

Each SW69-TTL uses two TTL Stepper Driver (A) boards—one for steering and one for wheel drive. Once the two drivers, absolute encoder and other bus devices have unique IDs, a single host controller can address them together.

STEP 01

Assign device IDs

Give every driver and encoder a unique ID, then verify communication with each device.

STEP 02

Join the bus

Connect the stepper motors, drivers and absolute encoder to the shared bus.

STEP 03

Build the application

Use the open examples as a starting point for an omnidirectional chassis controller.

CONFIGURATION & DEVELOPMENT

Bring-up without writing test code

FD software can discover bus devices, change IDs, plot feedback and configure driver parameters. Verify communication, steering and wheel drive on one module before moving to application control from a PC, SBC or MCU.

PC / Linux / SBC

Connect through TTL Adapter (A), then use the Python examples for device discovery, setup and motion control.

ESP32 / STM32 and other MCUs

Connect through a single-wire TTL interface and use the C++ or Arduino examples for embedded control.

Omnidirectional chassis control

After confirming wheel direction and steering zero, implement the kinematics for the chassis wheelbase, track width and module orientation.
