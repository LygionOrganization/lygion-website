PRODUCT POSITIONING

产品优势

SP3M72-E02 用于需要同步带传动和输出端角度反馈的场景。与在电机端（减速组输入端）估算输出角度相比，编码器直接读取同步轮输出端转动，反馈同步轮的实际角度和速度；结构紧凑，易于集成。

01

输出端直接反馈

角度测量位于同步轮输出端，适合负反馈传动后的实际位置和速度。

用于关节状态检测
02

12bit 绝对角度

单圈 0–4095 对应 360°，断电后仍可保留校准参数。

上电即可读取位置
03

机械结构紧凑

同步轮、F6906 法兰轴承、固定座和编码器集中在同一组件中。

减少独立零件设计
04

TTL 总线通信

通过 HC-1.25-3P 接口接入单线 TTL 总线，可与其它总线设备集中管理。

支持多种总线设备混用

MECHANICAL & BUS INTEGRATION

组装简单，易于集成

图片中为了展示同步轮转动时编码器与同步轮的相对运动关系，所以拆掉了径向磁铁和盖板。
固定轴安装孔用于连接静止结构，外圈安装孔用于连接随同步轮转动的连杆或输出件。编码器通过 HC-1.25-3P 接口接入 TTL 总线即可获取当前同步轮的绝对角度信息。

PC / SBC: Raspberry Pi & Jetson可通过 TTL Adapter (A) 的 USB 接口，使用 Python 例程获取当前关节角度/速度信息
ESP32 / STM32 / Arduino可使用单线 TTL 接口和相应 SDK 读取，提供开源例程。
多设备系统为设备设置独立 ID 后，可与灵影的总线设备或飞特的总线舵机混合使用。

FD SOFTWARE

零调试门槛

完成机械安装和接线后，可先通过 FD 软件搜索设备、读取当前角度并检查旋转方向。确认读数稳定后，再使用 Python、C++ 或 Arduino 示例接入控制程序。

01完成装配安装磁铁、盖板和输出端连接件。
02接入总线检查供电电压和 GND / VCC / Signal 线序。
03验证反馈使用 FD 软件检查角度、速度和设备 ID。
