供电提醒

对于低电压的总线设备，仅 USB 连接即可用于通信、调参和固件升级。但驱动设备时必须接入总线电源，并确保电压与所有连接设备匹配。多种电压或大电流系统供电方案可参考分组供电和供电解耦教程。

POWER GROUPING

支持分组供电

多设备系统不必仅用一路电源供电。TTL Adapter (A) 板载板间通信接口，可连接其它 TTL Adapter (A) 或 Hub Boards 实现分组供电/供电解耦。

查看分组供电和供电解耦完整教程
通信 S 信号与 GND 共地

你可以通过 Hub Boards 来扩展更多总线设备。

供电 各组独立接入

12V、24V 或大电流设备分别成组，每组电压必须匹配该组设备。

解耦 组间不连接电源正极

通信级联只传递 S 与 GND，可同时使用不同电压的总线设备。

必须 总线上设备 ID 不可以重复

分组供电后，也仍然是一根总线控制全部总线设备，所以总线设备 ID 必须唯一。

建议分组的情况 总线设备电压不同 执行器启动或堵转电流较大 线缆较长或设备较多 需要独立断电维护
