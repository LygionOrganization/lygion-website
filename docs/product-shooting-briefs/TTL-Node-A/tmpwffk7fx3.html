# TTL Node (A) 产品详情页补拍清单

## 使用原则

- 图片只呈现产品、配件、线材、安装位置和真实功能，不在图片内添加标题、参数、箭头或说明文字。
- TTL Node (A) 的功能较多，补拍重点是让用户快速理解它是“机器人上的功能节点”，而不是普通转接板。
- 优先补拍真实装机、S.BUS、RGB、PWM、总线接入这几类画面。
- RGB、PWM、S.BUS 等功能图建议拍摄真实工作状态，避免只拍接口空镜。
- 建议交付 JPG/WebP 成品与 PNG/TIFF/RAW 原图；长边不低于 3000 px。

## P0：详情页必须补齐

### 01. 主视觉套装图

- 内容：TTL Node (A)、总线线、USB-C 数据线、S.BUS 接收器、RGB 灯或小外设平铺。
- 用途：首页产品列表图、详情页首屏主图、淘宝首图备选。
- 构图：45 度斜俯拍，节点板为主体，配件围绕但不遮挡；左侧或上方保留干净留白。
- 重点：USB Type-C、S.BUS、PWM、RGB、总线接口都尽量可见。
- 交付：3:2 横图，建议 3600 x 2400 px；另拍 1:1 套装图。

### 02. 正反面标准产品图

- 内容：TTL Node (A) 正面、背面各一张，无遮挡、不接线。
- 用途：产品图库、规格介绍、电商参数区。
- 构图：垂直俯拍，产品居中，四边留白一致。
- 重点：30 x 35 mm 板体感、接口布局、丝印和焊点清晰。
- 交付：1:1，建议 3000 x 3000 px。

### 03. 机器人内部安装图

- 内容：TTL Node (A) 装在机械臂、移动底盘、末端执行器或机器人机身内部。
- 用途：解释它作为“功能节点”的存在价值。
- 构图：既能看到节点板位置，也能看到它连接的外设或总线线束。
- 重点：展示固定方式、线束走向、安装空间，不要只拍裸板。
- 交付：16:9 横图一张，4:5 竖图一张。

### 04. S.BUS 遥控接入特写

- 内容：航模接收器通过 2.54mm-3P 接入 TTL Node (A)，旁边可放遥控器。
- 用途：详情页“S.BUS 输入”功能说明。
- 构图：接收器、Node、线材和遥控器形成清晰关系；接口方向可辨。
- 重点：体现“遥控输入进入总线系统”，而不是只拍接收器。
- 交付：3:2 或 16:9。

### 05. RGB 状态灯工作图

- 内容：两路 RGB 灯实际点亮，建议拍摄 2-3 种颜色状态。
- 用途：说明状态可视化、调试反馈和运行提示。
- 构图：降低环境亮度但保留板体细节，灯光不过曝。
- 重点：RGB 颜色要明显，节点板和灯线连接关系可见。
- 交付：3:2；每种颜色一张，另拍一张多状态拼图素材原图。

### 06. PWM 输出控制外设

- 内容：PWM 输出口控制小风扇、灯带、小泵、末端小外设或其他低功率外设。
- 用途：解释“双路 PWM 可调输出”的实际用途。
- 构图：Node、外设、供电线和输出线都在画面中，外设处于工作状态。
- 重点：选择安全、低功率、画面直观的外设；不要接超过产品能力的负载。
- 交付：16:9 或 3:2。

### 07. 总线接入全景

- 内容：TTL Adapter (A) 或 Robot Driver、TTL Node (A)、TTL Servo / Encoder / Stepper 等设备共线。
- 用途：详情页“BUS INTEGRATION”区块。
- 构图：从主控到 Node，再到其他总线设备形成清晰链路。
- 重点：线材真实连接，设备 ID 或位置关系清楚。
- 交付：16:9，建议 3840 x 2160 px；另拍 3:2 近景。

## P1：显著提升说服力

### 08. FD 软件功能验证场景

- 内容：电脑屏幕显示 FD 软件或示例程序读取 S.BUS、控制 RGB/PWM 或搜索设备，前景放 Node 接线。
- 用途：详情页“先用软件点亮、调通、读到数据”章节。
- 构图：屏幕内容可辨，前景设备清晰，线材不乱。
- 重点：软件画面必须是真实连接状态。
- 交付：16:9，建议 3840 x 2160 px。

### 09. 末端执行器节点场景

- 内容：Node 安装在机械臂末端附近，连接状态灯、辅助外设或遥控输入。
- 用途：强化“末端功能节点”定位。
- 构图：保留部分夹爪、连杆或末端结构。
- 交付：4:5 竖图和 3:2 横图各一张。

### 10. 教学 / 原型开发桌面场景

- 内容：Node、电脑、开发板、遥控器、小外设在工作台上组成快速验证场景。
- 用途：突出上手门槛低，适合教学和原型。
- 构图：桌面简洁，主角明确。
- 交付：16:9。

## P2：可选增强

### 11. 包装清单平铺图

- 内容：TTL Node (A)、GH1.25-3P 线、5264-3P 转 PH2.0-3P 总线线、USB-A 转 USB-C 数据线。
- 用途：电商详情、购买确认。
- 交付：4:3，建议 3000 x 2250 px。

### 12. 接口细节组图

- 内容：USB Type-C、S.BUS、PWM、RGB、总线接口分别近拍。
- 用途：详情页图库和售前答疑。
- 构图：统一 45 度近景，接口占画面主体。
- 交付：4:3，每张建议 2400 x 1800 px。
