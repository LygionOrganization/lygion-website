# TTL Encoder E02 产品详情页补拍清单

## 使用原则

- 图片只呈现产品、线材、安装关系和真实使用场景，不在图片内添加标题、参数、箭头或大段说明文字。
- 页面文字由 HTML 承担，图片重点负责让用户一眼理解“装在哪里、怎么接、解决什么问题”。
- 优先使用浅灰、冷白或黑灰工程背景；黑色 PCB、焊点、丝印和接口必须清晰。
- 同一组素材保持一致的白平衡、光线方向、相机高度和留白比例，便于详情页并排展示。
- 建议交付 JPG/WebP 成品与 PNG/TIFF/RAW 原图；长边不低于 3000 px，保留无压缩原始文件。

## P0：详情页必须补齐

### 01. 主视觉套装图

- 内容：TTL Encoder E02 单板、径向磁铁、HC-1.25-3P 线材平铺。
- 用途：首页产品列表图、详情页首屏主图、淘宝首图备选。
- 构图：45 度斜俯拍，产品位于画面右侧或中心偏右，左侧保留 40%-45% 干净留白，方便 HTML 标题排版。
- 重点：板体直径感、接口方向、IC 区域、丝印和线材端子清晰可辨。
- 交付：3:2 横图，建议 3600 x 2400 px；另拍一张 1:1 居中产品图。

### 02. 正反面标准产品图

- 内容：E02 正面、背面各一张，无遮挡、不接线。
- 用途：详情页参数区、产品图库、后续电商规格图。
- 构图：镜头与 PCB 垂直，产品居中，四边留白一致。
- 重点：避免透视变形、强反光和阴影；所有丝印、孔位、焊点清晰。
- 交付：1:1，建议 3000 x 3000 px。

### 03. 磁铁与 IC 安装间距特写

- 内容：径向磁铁与编码器 IC 的同轴安装关系，建议用透明支架或剖面结构展示。
- 用途：替换当前“安装要点”示意图，让用户理解同心和间距要求。
- 构图：微距近景，磁铁、IC、转轴或支架在同一画面；画面留出少量空白供页面文字解释。
- 重点：展示约 1 mm 间距、同心关系和固定方式；不在图片内写文字标注。
- 交付：4:3 或 3:2，建议 3000 x 2250 px。

### 04. 同步轮 / 齿轮输出端安装场景

- 内容：E02 安装在同步轮、齿轮、减速器或转向输出端，能看出它检测的是机械输出端角度。
- 用途：解释“不是估算电机角度，而是读取真实输出端角度”。
- 构图：传动件占画面主体，编码器可见，转轴与磁铁关系清楚。
- 重点：不要只拍裸板；必须体现机械结构和输出端反馈价值。
- 交付：16:9 横图一张，4:5 竖图一张。

### 05. 多个 E02 接入同一 TTL 总线

- 内容：2-3 个 E02、TTL Adapter (A)、Hub 或主控板接入同一总线。
- 用途：详情页“多个编码器，共用一条总线”区块。
- 构图：从左到右形成清晰链路，线材真实连接，设备间距均匀。
- 重点：每个编码器都能看出独立位置；如果方便，可用小标签临时标出 ID，但最终发布图不放文字。
- 交付：16:9，建议 3840 x 2160 px；另拍 3:2 近景版本。

### 06. 尺寸比例图

- 内容：E02 与手指、硬币、尺子或常见小型关节零件同框。
- 用途：强调约 16 mm 板体和紧凑安装优势。
- 构图：主体居中，参照物不要喧宾夺主。
- 重点：比例真实，不使用夸张透视。
- 交付：3:2 或 1:1，建议 3000 px 长边。

## P1：显著提升说服力

### 07. 机械臂关节安装图

- 内容：E02 安装在小型机械臂、Leader Arm 或关节模组输出端。
- 用途：强化机器人关节反馈场景。
- 构图：保留部分机械臂结构，既能看出整体应用，也能看到 E02 的安装位置。
- 交付：16:9 横图，建议 3840 x 2160 px。

### 08. 灵巧手 / 小型连杆安装图

- 内容：E02 安装在手指、连杆或小型摆臂转轴附近。
- 用途：展示紧凑空间内的角度反馈能力。
- 构图：近景为主，避免背景杂乱。
- 交付：4:5 竖图与 3:2 横图各一张。

### 09. FD 软件读数场景

- 内容：电脑屏幕显示 FD 软件或示例程序读数，前景放 E02 与 Adapter 接线。
- 用途：详情页“用起来很简单”章节，证明能快速读出角度和速度。
- 构图：屏幕内容可辨但不过曝，前景产品清晰。
- 重点：拍摄前确认软件画面为真实连接状态。
- 交付：16:9，建议 3840 x 2160 px。

## P2：可选增强

### 10. 包装清单平铺图

- 内容：E02、磁铁、线材、固定螺丝或随包配件。
- 用途：电商详情、购买决策辅助。
- 交付：4:3，建议 3000 x 2250 px。

### 11. 暗色科技风主图

- 内容：E02 与磁铁在黑灰背景上做低反射布光。
- 用途：首屏或社媒宣传备用。
- 重点：黑色 PCB 不要糊成一片，边缘和接口要有轮廓光。
- 交付：16:9，建议 3840 x 2160 px。
