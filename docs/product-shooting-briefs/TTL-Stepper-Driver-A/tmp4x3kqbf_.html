# TTL Stepper Driver (A) 产品详情页补拍清单

## 使用原则

- 图片只呈现真实硬件、线材、机构和连接关系，不在图片内添加标题、参数、箭头或说明文字。
- 页面文字由 HTML 承担，图片负责证明“步进电机可以像总线设备一样接入机器人系统”。
- 优先补拍“驱动板 + 电机 + 机构”的真实画面，避免页面停留在裸板说明。
- 所有接线必须真实可运行，拍摄前确认供电、电机相线、限位和总线连接正确。
- 建议交付 JPG/WebP 成品与 PNG/TIFF/RAW 原图；长边不低于 3000 px。

## P0：详情页必须补齐

### 01. 主视觉套装图

- 内容：TTL Stepper Driver (A)、5264-3P 总线线、步进电机连接线、小型步进电机平铺。
- 用途：首页产品列表图、详情页首屏主图、淘宝首图备选。
- 构图：45 度斜俯拍，驱动板为主体，电机和线材作为配套关系出现；左侧保留约 40% 留白。
- 重点：电机接口、总线接口、电源接口、板上丝印和散热区域清晰。
- 交付：3:2 横图，建议 3600 x 2400 px；另拍 1:1 套装图。

### 02. 正反面标准产品图

- 内容：驱动板正面、背面各一张，无遮挡、不接线。
- 用途：产品图库、规格介绍、电商参数区。
- 构图：垂直俯拍，四边留白一致。
- 重点：接口、端子、孔位、丝印清晰，不要有强反光。
- 交付：1:1，建议 3000 x 3000 px。

### 03. 完整接线图

- 内容：TTL Adapter (A) 或主控板、TTL Stepper Driver (A)、步进电机、电源、总线线材完整连接。
- 用途：详情页“系统接入”区块，降低用户接线理解成本。
- 构图：从主控/Adapter 到驱动板，再到电机形成清晰链路；线材尽量不交叉遮挡接口。
- 重点：电源输入、TTL 总线、电机相线三类连接必须容易分辨。
- 交付：16:9，建议 3840 x 2160 px；另拍 3:2 近景。

### 04. 位置模式应用场景

- 内容：驱动小转台、小关节、丝杆滑台或摆臂定位。
- 用途：解释“发送目标位置，驱动板完成底层运动控制”。
- 构图：机构占主体，驱动板和电机在画面中可见。
- 重点：让用户能立即看出这是定位控制，不是单纯电机空转。
- 交付：16:9 横图一张，4:5 竖图一张。

### 05. 速度模式应用场景

- 内容：小轮、输送轮、旋转轮或连续旋转机构。
- 用途：展示速度控制、连续正反转和运动方向。
- 构图：可拍摄静态硬件，也可拍摄带轻微运动感的版本；最终发布优先清晰静态图。
- 重点：电机、负载轮和驱动板三者关系清楚。
- 交付：3:2 或 16:9。

### 06. 同步模式 / 双电机机构

- 内容：双丝杆升降台、双电机并联机构或两轴同步动作展示。
- 用途：突出同步输入/输出的实际价值。
- 构图：两个电机或两块驱动板在画面中形成对称关系，机构动作关系一眼可懂。
- 重点：体现“多轴一致动作”，不要只拍两块板并排。
- 交付：16:9，建议 3840 x 2160 px。

### 07. 限位保护特写

- 内容：最小位 / 最大位限位开关接线与触发位置。
- 用途：替换当前偏示意的限位图，说明底层保护逻辑。
- 构图：限位开关、运动方向、驱动板限位接口都可见；可以保留机构局部。
- 重点：拍摄真实触发位置，线材不要挡住开关。
- 交付：4:3 或 3:2。

## P1：显著提升说服力

### 08. FD 软件调试场景

- 内容：电脑屏幕显示 FD 软件中的驱动板在线、参数或运动控制界面，前景放驱动板和电机。
- 用途：详情页“用软件和例程快速上手”章节。
- 构图：屏幕不过曝，前景接线清楚。
- 重点：软件画面必须是真实连接状态，建议显示 ID、状态、电流或速度相关信息。
- 交付：16:9，建议 3840 x 2160 px。

### 09. 多驱动板总线场景

- 内容：2-3 块 Stepper Driver 接入同一 TTL 总线，可混接 Encoder 或 Servo。
- 用途：展示多设备总线化和机器人底层运动网络。
- 构图：从左到右形成主控、Hub、多个驱动板、电机的链路。
- 交付：16:9。

### 10. 真实机器人安装图

- 内容：驱动板固定在机械臂、底盘、滑台或小型机器人内部。
- 用途：增强产品可信度，让用户理解它不是实验板，而是可装机部件。
- 构图：展示固定方式、线束走向和周边结构。
- 交付：3:2 横图与 4:5 竖图各一张。

## P2：可选增强

### 11. 散热与安装空间图

- 内容：驱动板在通风位置、支架或安装柱上的固定方式。
- 用途：辅助说明长时间运行和装机注意事项。
- 交付：3:2。

### 12. 包装清单平铺图

- 内容：驱动板、总线线、电机连接线、随包附件。
- 用途：电商详情、购买确认。
- 交付：4:3，建议 3000 x 2250 px。
