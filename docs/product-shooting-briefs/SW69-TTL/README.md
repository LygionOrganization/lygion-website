# SW69-TTL 产品详情页拍摄清单

## 先确认新版参数

页面已按用户确认信息将单模组承载能力更新为 50 kg。正式发布前，请再确认新版以下参数是否沿用旧版：

- 外形尺寸：172 × 135 × 82 mm。
- 模组重量：约 1.6 kg。
- 工作电压：DC 9–25.2V；峰值电流：3A。
- 轻载移动速度：19.5 m/min。
- 转向扭矩：40 kg·cm；驱动轮扭矩：14 kg·cm。
- 转向 / 驱动转速：25 / 90 rpm。
- 安装孔位：8 × M6，主要孔距 108 × 40 mm。

## 拍摄原则

- 只拍产品、线材、底盘和测试工装，不在图片内添加标题、参数、箭头或说明文字。
- 图片说明统一由 HTML 呈现，便于 SEO、翻译和后续参数更新。
- 统一使用浅灰或中性白背景；黑色结构件需保留纹理与边缘层次。
- 交付 JPG 与无损 PNG/TIFF 原图，长边不低于 3000 px，并保留 RAW 文件。
- 必须使用新版 50 kg 版本实物，避免旧版和新版素材混用。

### 02. 50 kg 承载测试证据图

- 内容：单模组安装在刚性测试架上，承载 50 kg 标准砝码或经过称重确认的载荷。

- 重点：明确测试是静态还是动态、载荷方向、地面、速度、运行时间和安全系数。
