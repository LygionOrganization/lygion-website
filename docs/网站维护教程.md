# 灵影主站维护教程

这份教程说明如何编辑主页文字、更新产品，以及如何接入一个独立产品详情页资料包。

## 1. 本地预览

在项目根目录运行：

```bash
npm run dev
```

然后打开：

```text
http://127.0.0.1:5173/zh/
```

修改文件后，浏览器通常会自动刷新。如果没有刷新，手动刷新页面即可。

## 2. 修改主页文字

主页上的中英文文案主要在这个文件里：

```text
src/data/i18n.ts
```

常用字段说明：

```ts
heroTitle: "简单连接 快速构建",
heroLead: "从总线设备、驱动模组...",
heroPrimary: "探索产品体系",
heroSecondary: "打开灵影 Wiki",
modulesTitle: "一个主站，承载不断增长的机器人产品线",
featuredTitle: "产品正在从这里生长",
ctaTitle: "为快速迭代而设计，也为公开发布而准备",
ctaLead: "产品数据集中维护...",
```

中文页面改 `zh` 下面的字段，英文页面改 `en` 下面的字段。

如果只改文字，不需要修改页面结构。

## 3. 修改顶部导航文字和 Wiki 链接

顶部导航文字也在：

```text
src/data/i18n.ts
```

导航文案位置：

```ts
nav: {
  wiki: "灵影Wiki",
  busDevices: "总线设备",
  robotModules: "机器人模组",
  robotSystems: "机器人整机",
  lygionOpen: "灵影开源"
}
```

Wiki 外部链接位置：

```ts
export const wikiLinks = {
  zh: "https://wiki.lygion.ai/",
  en: "https://lygionorganization.github.io/lygion-wiki/"
};
```

## 4. 更新产品列表

产品数据集中维护在：

```text
src/data/products.ts
```

每个产品都是 `products` 数组里的一个对象。新增产品时，复制一个已有产品对象，然后修改字段。

产品对象示例：

## 5. 产品字段说明

`slug`

产品唯一标识。普通 Astro 产品详情页会生成：

```text
/zh/products/{slug}/
/en/products/{slug}/
```

示例：

```ts
slug: "joint-module-alpha"
```

`module`

产品所属模块，只能使用以下四种：

```ts
"bus-devices"    // 总线设备
"robot-modules"  // 机器人模组
"robot-systems"  // 机器人整机
"lygion-open"    // 灵影开源
```

`status`

产品状态，目前可选：

```ts
"concept"
"prototype"
"available"
"open"
```

目前页面没有重点展示这个字段，但可以作为后续筛选、标签或排序使用。

`image`

产品卡片主图。首页产品列表、模块产品列表都会显示这张图。

普通产品建议放在：

```text
public/assets/products/
```

然后这样引用：

```ts
image: "/assets/products/joint-alpha.svg"
```

如果产品使用独立详情页资料包，主图通常放在该产品资料包内：

```text
public/product-pages/dw69/assets/hero-product.jpg
```

然后这样引用：

```ts
image: "/product-pages/dw69/assets/hero-product.jpg"
```

这就是“外部入口的主图”更换位置。

`detailPath`

可选字段。如果填写，点击产品卡片会跳转到这个地址。

适合复杂详情页资料包：

```ts
detailPath: "/product-pages/dw69/index.html"
```

如果不填写 `detailPath`，系统会自动使用 Astro 默认产品详情页：

```text
/zh/products/{slug}/
/en/products/{slug}/
```

`name`

产品名称，中英文都要写：

```ts
name: {
  zh: "DW69 机器人底盘驱动轮模组",
  en: "DW69 Chassis Drive Wheel Module"
}
```

`summary`

产品卡片上的短简介。

`description`

默认 Astro 产品详情页上的长简介。

如果产品使用 `detailPath` 跳转到独立 HTML 详情页，这个字段主要作为备用数据保留。

`highlights`

产品亮点列表，用在默认 Astro 产品详情页。

`specs`

产品参数表，用在默认 Astro 产品详情页。

## 6. 两种产品详情页维护方式

### 方式 A：普通产品，使用 Astro 默认详情页

适合内容比较简单的产品。

只需要维护：

```text
src/data/products.ts
```

并且不要填写 `detailPath`。

示例：

```ts
{
  slug: "joint-module-alpha",
  module: "robot-modules",
  image: "/assets/products/joint-alpha.svg",
  name: { ... },
  summary: { ... },
  description: { ... },
  highlights: { ... },
  specs: { ... }
}
```

页面会自动生成：

```text
/zh/products/joint-module-alpha/
/en/products/joint-module-alpha/
```

### 方式 B：复杂产品，使用独立详情页资料包

适合 DW69 这种有完整 HTML、CSS、大量图片素材的详情页。

资料包放在：

```text
public/product-pages/{product-slug}/
```

推荐结构：

```text
public/product-pages/dw69/
  index.html
  styles.css
  assets/
    hero-product.jpg
    rear-product.jpg
    dimension-drawing.png
    ...
```

然后在 `src/data/products.ts` 中添加产品：

```ts
{
  slug: "dw69-drive-wheel-module",
  module: "robot-modules",
  image: "/product-pages/dw69/assets/hero-product.jpg",
  detailPath: "/product-pages/dw69/index.html",
  name: { ... },
  summary: { ... },
  description: { ... },
  highlights: { ... },
  specs: { ... }
}
```

注意：`detailPath` 建议写到 `index.html`，不要只写目录：

```ts
detailPath: "/product-pages/dw69/index.html"
```

这样在本地开发服务器和静态部署环境里都更稳定。

## 7. 更换独立详情页入口主图

以 DW69 为例，入口主图现在是：

```text
public/product-pages/dw69/assets/hero-product.jpg
```

如果你要替换主图，可以：

1. 把新图片放入 `public/product-pages/dw69/assets/`
2. 修改 `src/data/products.ts` 中 DW69 产品的 `image`

例如：

```ts
image: "/product-pages/dw69/assets/new-hero.jpg",
```

如果你直接用新图覆盖旧的 `hero-product.jpg`，则不需要修改代码。

## 8. 修改四个模块的信息

四个模块也在：

```text
src/data/products.ts
```

位置是 `modules` 数组。

示例：

```ts
{
  id: "robot-modules",
  accent: "amber",
  navKey: "robotModules",
  name: { zh: "机器人模组", en: "Robot Modules" },
  summary: {
    zh: "可复用的执行、感知与计算单元，加速原型到产品。",
    en: "Reusable actuation, perception, and compute units from prototype to product."
  },
  description: {
    zh: "机器人模组把复杂能力打包成独立单元...",
    en: "Robot modules package complex capabilities..."
  }
}
```

`summary` 用在首页模块卡片。

`description` 用在模块详情页。

## 9. 修改页面结构或布局

一般只改文字和产品时，不需要动页面文件。

如果要改首页结构，编辑：

```text
src/pages/[lang]/index.astro
```

如果要改模块页结构，编辑：

```text
src/pages/[lang]/modules/[module].astro
```

如果要改默认产品详情页结构，编辑：

```text
src/pages/[lang]/products/[slug].astro
```

如果要改全站导航、页脚、页面标题，编辑：

```text
src/layouts/BaseLayout.astro
```

如果要改全站视觉样式，编辑：

```text
src/styles/global.css
```

## 10. 更新后的检查步骤

每次更新后建议运行：

```bash
npm run build
```

如果构建成功，说明静态页面可以正常生成。

常用预览地址：

```text
http://127.0.0.1:5173/zh/
http://127.0.0.1:5173/en/
http://127.0.0.1:5173/zh/modules/robot-modules/
http://127.0.0.1:5173/product-pages/dw69/index.html
```
