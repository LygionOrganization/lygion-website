核心优势

不是单独一个电机，而是一套更适合机器人机构开发的执行器方案

资料里的重点并不在“堆参数”，而在于把机械输出、角度反馈、总线接入和常用控制方式放到同一套工程可用方案里。页面只保留现有素材能直接证实的能力与限制。

01

约 40kg·cm 输出扭矩

资料图明确给出约 40kg·cm 输出扭矩，适合关节、摆臂、转台等需要放大扭矩的小型机器人机构。

02

输出端直接测角

编码器安装在输出端，能直接读取输出轴绝对角度，比只看电机端位置更适合关节应用与输出端状态核对。

03

开机免回零

编码器支持保存校准参数，掉电后仍可保存角度信息；再次上电时可先读取当前绝对角度，减少重复回零和重新校准。

04

支持三种常用控制模式

现有资料列出位置模式、速度模式与从动模式，便于做角度控制、连续转动和多轴同步动作。

05

TTL 总线易集成

驱动板与编码器均采用 TTL 总线协议，现有素材说明同一根总线最多可挂 252 个设备，适合多节点机器人系统扩展。

06

开发资料直接配套

资料包已给出 Python / C++ SDK、示例和 STEP 模型，既适合上位机联调，也方便结构设计和二次开发。

结构定位

减速步进电机一体机，加上同步带二级减速和输出端安装面

现有素材显示，这套执行器以减速步进电机为基础，通过同步轮同步带二级减速进一步放大输出扭矩，并在输出端预留安装孔位，方便连接摆臂、连杆、转台或其它机构件。

  • 电机减速比：5.1818182:1
  • 同步带减速比：72 / 20 = 3.6:1
  • 同步带型号：HTD270-3M-15mm
  • 输出端安装接口：8 × M3，PCD φ60
适用方向：页面现有文案和图片都指向机器人关节、摆臂、转台等角度控制场景，不把它包装成适用于所有负载与所有速度需求的通用动力总成。

控制模式

位置、速度、从动三类控制方式覆盖常见机器人动作

现有资料给出的控制模式已经足够覆盖多数原型与小批量设备开发场景。你不需要围绕传统 STEP / DIR 自己搭全部底层逻辑，而是可以用更直接的总线指令来组织多轴动作。

位置模式适合关节角度控制、多圈累计位置管理与转台定点动作。
速度模式适合连续转动类场景，资料中同步展示了柔性启停与心跳保护能力。
从动模式适合多电机完全同步动作，便于做镜像机构、联动轴和从动轴。
输出角度反馈配合输出端绝对值编码器，可对比实际角度，做丢步或打滑检测。

绝对值反馈

上电先读当前位置，不必每次都重新回零

这类结构最大的工程价值之一，是把输出端角度检测直接做进执行器方案里。对于机械臂、摆臂和转台，这往往比单纯“能转起来”更重要，因为它直接影响初始化流程、异常检测和系统恢复效率。

  • 掉电保存角度：编码器支持保存校准参数，减少重新设定步骤。
  • 开机免回零：上电可先读取当前输出端绝对角度，再决定控制逻辑。
  • 便于异常检测：可对比输出端真实角度，辅助发现丢步、打滑或偏差。
限制说明：资料中“约 0.00603° 理论控制分辨率”是计算值，实际表现会受到负载、安装精度和传动状态影响，不能把理论值直接等同于整机最终定位精度。

系统集成

统一 TTL 总线，减少额外布线和多设备接入复杂度

现有资料明确说明，驱动板和编码器都采用 TTL 总线协议，编码器可接入驱动板并并入同一根总线。对于要同时控制多个关节、多个执行器和多类总线设备的机器人系统，这种布线方式比传统离散脉冲控制更容易扩展。

最多 252 个设备同一根 TTL 总线支持多设备扩展，但配置前需要保证设备 ID 不重复。
可混合接入现有素材写明可与灵影 TTL Encoder、飞特 STS / HLS 系列总线舵机共线使用。
PC 与 SBC 接入资料图给出 PC、树莓派、Jetson、RK 等平台，通过 TTL Adapter (A) 接入总线。
MCU 接入ESP32、ESP32S3、STM32、Arduino 可通过 C / C++ 例程接入当前方案。

开发支持

Python / C++ SDK、示例和 STEP 模型一起提供

资料包不仅给了参数和外观图，也把开发与结构设计所需资料放在一起。对于想快速验证机构、总线通信和应用逻辑的团队，这比单独拿到一份机械图更省时间。

  • 支持平台：Linux、Windows、MacOS、树莓派、Jetson、ESP32、STM32、Arduino
  • 软件资料：Python / C++ SDK 与例程
  • 结构资料：STEP、PDF、DXF 图纸

使用提醒

把该记住的边界条件提前写清楚

  • 设备 ID 不可重复：同一根 TTL 总线上的设备地址必须唯一。
  • 速度条件需对应：25rpm 来自 24V / 1.5A 条件下的现有资料，不应直接外推到其它供电和负载工况。
  • 理论分辨率不等于最终精度：实际控制效果与负载、安装精度、皮带状态和机构刚性有关。
  • 机械设计看正式图纸：尺寸展示页用于快速选型，最终结构设计请使用 PDF、DXF 和 STEP 文件。
